Retry with exponential backoff

src/retry.ts, test/retry.test.ts

This area adds src/retry.ts, a small helper that retries an async call when it fails for a transient reason: a network error code or a 5xx reply. 4xx replies such as a denied key fail at once. Waits start at 200 ms, double up to 10 s and are jittered.

Step 1 of 3 · Decide which failures deserve another try Press n / p for next / previous

1Decide which failures deserve another try

isRetryable treats the error as an object with optional code and status fields. It returns true when code is in RETRYABLE_CODES (ECONNRESET, ETIMEDOUT, EAI_AGAIN, EPIPE) or when status is 500 or more. Everything else, including every 4xx reply, is final.

11+
12+export function isRetryable(err: unknown): boolean {
13+ const e = err as { code?: string; status?: number };
14+ if (e.code && RETRYABLE_CODES.has(e.code)) return true;
15+ return typeof e.status === 'number' && e.status >= 500;

WHAT TO CHECK
  • Only four error codes are retried. Confirm ECONNREFUSED and similar transient errors should really fail at once.
  • Every status ≥ 500 is retried, including 501 Not Implemented, which a retry will not fix.
