Start your first project

  1. Register a project folder — the path stays on this machine, DigestIT only reads it.
  2. Work in it with any tool: an editor, an AI agent, a script.
  3. Come back and press Explain. Only then does anything leave this machine.
What Explain sends

Pressing Explain sends the changed diff — not the whole repository — to Claude Code · claude-sonnet-5-5, the provider configured on this server.

DigestIT itself never writes to your project. Explanations and settings are stored outside it, in DigestIT's own data directory.
